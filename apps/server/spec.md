# Objetivo
Desenvolver o backend de um trabalho de faculdade

# Tema
Trabalho gira em volta de construir uma plataforma de aplicação de avaliações. Professores podem criar avaliações e alunos podem fazer elas. Depois de fazer uma prova o aluno pode checar o seu desempenho. O sistema também possui admnistradores. Eles serão responsáveis pela parte de gerenciamento de credenciais o tema é fazer uma plataforma para uma instituição de ensino então professores e alunos não podem criar contas por si só.

O sistema deve ser denvolvido em ingles mas seu conteudo sera armazenado em pt-br. É um trabalho de faculdade não quero 31992131 algoritmos foda, quero o simples que funciona. Estamos atualmente com 2 containers o do app e o do db. Estamos usando Nest com Type ORM, e SQL Server da microsoft.
